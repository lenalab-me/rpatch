# Example client

## 概要

このクライアントはローカルの設定ファイルを読み取り、リクエストに必要な接続先とタイムアウトをまとめます。外部依存はなく、設定の読み取りとリクエストのオプション生成を分けているので、ネットワーク通信を行わずに設定の処理を確認できます。

## 使い方

`node test.mjs` で動作を確かめます。アプリケーションからは `readConfig()` で設定を読み、`requestOptions(config)` でオプションを作ります。

## データ形式

| キー | 型 | 意味 |
| --- | --- | --- |
| endpoint | string | 接続先URL |
| timeoutMs | number | タイムアウトのミリ秒数 |

## 設計メモ

設定はJSONファイルに保存します。リクエストのオプションには `url` と `timeout` を使います。
